# Capture examples

Static instructional assets shown on the capture screens. These are app assets,
NOT user photos — they ship in the public bundle and are served publicly. Use
only images you own the rights to and are comfortable making public. Do not use
a real user's base photo here.

## base-good.png

Shown on the base photo capture screen beside the REQUIRED rules.

- **Path:** `public/examples/base-good.png` (served at `/examples/base-good.png`)
- **Content:** a correct base photo — full body head to shoes, plain wall, even
  light, fitted clothes.
- **Aspect ratio:** 3:4 portrait (it renders in a 3:4 frame; other ratios get
  cropped to fill).
- **Size:** at least 1080×1440, ideally under ~500 KB.

Until this file exists the screen shows a styled "Example" placeholder of the
exact size. Add the file and redeploy — it appears automatically, no code change.
